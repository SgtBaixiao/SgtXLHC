NOTION CONNECT GUIDE — 一次性操作

把 Notion 接到网站
从 0 到第一篇随笔 （约 5 分钟）

先记一条关键认知：Notion 的 token 不是「找」出来的，是「创建」出来的。它不会在设置里给你现成的 token——你必须去「集成管理」页新建一个集成，它才生成一个 token 给你复制。找不到 token，大概率就是还没创建集成。下面 6 步按顺序走。

NOTION INTEGRATION DATABASE ID SHARE CONNECTION ≈ 5 MIN

01创建集成，拿到 token

  1. 打开集成管理Notion 左下角 Settings（设置）→ Connections（连接）→ 右上角 Develop or manage integrations（开发或管理集成）。或直接访问 notion.so/my-integrations。
  2. 新建集成点 + New integration，名称随便填（如 personal-site）。Workspace 下拉必须选对——存放随笔数据库的那个工作区。
  3. 最小权限Capabilities 只勾 Read content（读取内容），其余全关。这是本项目的安全要求。
  4. 复制 tokenSubmit 后页面上出现 Internal Integration Token——这就是你的 NOTION_TOKEN，形如 ntn_ 开头（旧格式 secret_，代码两者都认）。
  5. 立刻存好只显示这一次，关掉页面就看不到了；丢了只能重新生成。

02找到数据库 ID

打开随笔数据库页面，看浏览器地址栏：

https://www.notion.so/<工作区>/<数据库ID>?v=...

? 前面那一长串 32 位字符就是 database_id。

03授权集成访问数据库（最容易漏的一步）

光有 token 不够——集成默认看不到任何页面，必须手动授权。漏了这步，token 再对也会报 404 could not find database。那不是 token 错，是没授权。

  1. 打开数据库页面右上角 ...（三个点）菜单 → Connections（连接）。
  2. 添加集成搜索并选中刚创建的集成名（如 personal-site），确认列表里出现它。

这一步必须在数据库页面本身（能看到文章列表的那页）操作，不是在库里的某篇文章内页。

04建好字段（代码按固定列名读）

项目代码 scripts/lib/notion-core.mjs 按固定列名读数据。给数据库建齐这几列，列名与类型都要对：

列名类型说明
Nametitle文章标题（Notion 默认就有）
日期date发布日期，决定归档排序与 URL 前缀
Tagsmulti_select标签，可空
摘要rich_text列表页摘要，可空
Publishedcheckbox勾上才会上传到网站
Slugrich_textURL 别名，可空；留空自动用标题生成

05本地测试

cd personal-site
# 把 token 写进 gitignored 的 .env.local（推荐，避免每次敲）
# NOTION_TOKEN=ntn_xxx

npm run notion:list -- --database <db_id>

看到文章列表 = 第 01~04 步全部打通。接着发布：

# 发布全部已勾选 Published 的文章
npm run notion:publish -- --database <db_id> --all

发布后在 src/content/essays/ 生成 Markdown。本机预览 npm run dev → 打开 http://localhost:4321/essays。满意后加 --commit 重跑，自动 git 提交推送，触发构建上线。

可选：想免命令行、在浏览器里勾选上传，用本地发布桥 —— NOTION_TOKEN=ntn_... npm run bridge -- --database <db_id>，打开 http://localhost:4174。

06存好 token（两条路径，都不入库）

  • 本地：写进 .env.local（已在 .gitignore，绝不提交）。
  • GitHub Actions（CI）：仓库 → Settings → Secrets and variables → Actions → New repository secret → 名字 NOTION_TOKEN，值粘贴 token。

07安全边界（不能省）

  • token 是「钥匙」，能读写所有共享给该集成的页面 → 权限只开 Read content。
  • 绝不提交进 git（历史会永久保留已删的密钥，泄了只能轮换）。
  • ntn_ PAT 1 年有效 → 日历里设个续期提醒。
  • 公开网站不直连 Notion：token 只在本机 / CI，网页只展示构建产物。
