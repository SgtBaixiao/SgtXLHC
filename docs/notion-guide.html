Notion 发布指南

先在本地环境或被 Git 忽略的 .env.local 配置 NOTION_TOKEN 和 NOTION_DATABASE。数据库需要 Name、日期、Tags、摘要、Published、Slug 属性，其中日期必须有效，Published 需要勾选。

npm ci
npm run notion:list -- --database <database_id>
npm run notion:publish -- --database <database_id> --page <page_id>
npm run bridge -- --database <database_id>

浏览器打开 http://127.0.0.1:4174。覆盖和提交推送默认关闭。草稿不能发布，同源文章改名保留文件和 URL；URL 冲突和其他来源文件不会被覆盖。

CLI 使用 --force 覆盖同源文章，使用 --commit 明确提交推送。推送要求暂存区为空、目标文件无本地编辑、本地与远端历史一致。失败后先检查本地文件与 Git 状态，系统不会自动重试推送。
