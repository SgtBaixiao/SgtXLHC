站点维护指南

使用 Node 22.12 及以上版本。构建与预览使用相同 base，检查通过后再通过 PR 交评审。

npm ci
npm run validate
npm run build:project
ASTRO_BASE=/SgtXLHC npm run preview
npm run sync:status -- --agent pi --status idle
npm run progress -- --scratch /path/to/.scratch

状态与进度写入有校验和跨进程锁。旧数据损坏时保留原文件并报错。锁不会自动抢占，进程中断后需要确认原进程与工作已结束，再备份产物并清理对应锁目录。

PR 在 Node 22、24 上检查，Chromium 验证桌面与移动布局。主分支仍按原 Pages 工作流发布，纯状态更新跳过重建。
